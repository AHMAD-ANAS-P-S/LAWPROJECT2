# Tamil Raw Library — Legal Acts Subscription Platform

A comprehensive digital platform for Indian Government Acts, Rules, Amendments, and Legal Updates. Faithfully engineered to reproduce the 11 authoritative reference designs with complete pixel accuracy and full responsiveness across PC, Laptop, Computer, and Mobile screens.

---

## 🏛️ Project Features

- **Auth & Onboarding**:
  - **Login Portal**: Golden emblem, show/hide password, Forgot Password modal, Google OAuth integration, links to Sign Up.
  - **Sign Up Page**: Terms of service agreement, real-time validation, responsive mobile & desktop view.
- **Main Dashboard**:
  - Personalized welcome banner for **AHMAD ANAS P S** with active subscription tier.
  - Global statutory search across Acts, Rules, Sections, and Amendments.
  - Quick action shortcuts (Browse Acts, Rules, Amendments, Notes, Bookmarks).
  - Highlighting 3 core statutory modules (Acts, Rules, Amendments) with custom artwork.
  - Recently Viewed statutory documents with instant modal viewer.
  - Explore by legal category (Criminal Laws, Civil Laws, Constitution, Labour Laws, Environmental Laws, Taxation Laws, Commercial).
- **Browse Acts**:
  - Central & State Act listings with status badges (Principal, In Force, Amending).
  - Search by Act name, enactment year, and keywords.
  - Jurisdiction & Year of Enactment filter panel.
  - Interactive Act details & section-by-section breakdown modal.
  - Quick bookmark toggle.
- **Browse Rules**:
  - Central & State Rules and Regulations under statutory Acts.
  - Parent Act citations and Gazette notification references.
  - Year of notification and category filters.
- **Amendments & Updates**:
  - Gazette notifications and statutory amendments.
  - Side-by-side Before/After statutory amendment comparison.
  - Gazette notification download actions and subject filters.
- **Advanced Search**:
  - 5 search modes: Universal Search, Exact Phrase Search, Section Search, Cross-Reference Search, and Advanced Search.
  - Multi-parameter filter engine (Act Type, Keyword Type, Jurisdiction, Year Range, Document Type).
- **My Notes**:
  - Legal research notebook with full CRUD operations.
  - Color-coded tags (Purple, Gold, Magenta, Green, Blue).
  - Citation linkage to Central & State Acts.
  - Search and filter notes by statutory topic.
- **Bookmarks**:
  - Organized repository for saved Acts, Rules, Sections, and Amendments.
  - Star / mark important documents.
  - Instant modal inspection and removal controls.
- **Subscription Details**:
  - Subscription tier status badge: **Tamil + English Yearly Package**.
  - Interactive Upgrade Plan, Renew Plan, and Update Billing modals.
  - Complete billing history and downloadable invoice receipts.
  - Lady Justice legal sidebar artwork.
- **Help & How to Use**:
  - 3 video tutorials with interactive video player modal.
  - Collapsible legal research FAQ accordions.
  - Interactive Contact Support ticket modal.

## 📱 Responsive Across All Devices

- **Desktop, PC & Wide Monitors (1920px+)**:
  - Immersive velvet royal purple atmosphere without harsh edge cuts.
  - Exact pixel-matched positioning of all statutory headers, banners, and forms.
  - Sticky sidebar with gold active indicators and contextual bottom legal illustrations (Lady Justice / Books & Gavel).
- **Laptops (1366px – 1536px)**:
  - Scaled layouts ensuring zero horizontal clipping.
- **Mobile Phones (375px – 430px)**:
  - Off-canvas sliding drawer menu toggled via hamburger button in the sticky mobile header.
  - Compact header controls with language switchers (`English` / `தமிழ்`), notifications, and profile.
  - Responsive single-column cards and wrapped action buttons with touch targets.

---

## 🛠️ Technology Stack

- **Frontend**: React 18, Vite 5, Tailwind CSS, Lucide React Icons.
- **Backend**: Node.js, Express, RESTful APIs with JSON file persistence (`server/store.json`).
- **Styling**: Tailored purple/violet/magenta/gold legal palette with custom gradients and shadows.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Application
```bash
# Starts both Express backend and production server
npm start
```

Or for development:
```bash
npm run dev
```

### 3. Open in Browser
Navigate to:
```
http://localhost:5000
```
